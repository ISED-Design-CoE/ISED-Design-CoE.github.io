Text format for terrestrial spectrum licence site data upload

Learn about the format, validation rules, and errors when uploading spectrum licence site data.

Viewing the status of your licence
Use the Spectrum Licence Site Data Status Report to check when your next upload date is due.



Download the provided .csv file template
Use the following CSV template for your site data.

Field names

Letter Name

A

Spectrum licence number

The number of your spectrum licence.

Format

  • Must be exactly 9 digits long including any leading zeroes
  • Must not include the licence version number
  • Must belong to an account in your web profile
  • Must be a granted (paid) spectrum licence, and not expired

Example

010898101

Potential errors

The licence number does not contain a leading 0, the licence number does not belong to your account, the licence number is not in Granted status, or the licence is expired.

B

Upload reference number

A number, or any other text, for your own use (this field is optional).

Format

Maximum length of 63 characters.

Example

Monthly upload, March 2023

C

Contact name

Name of the person who may be contacted about this site.

Format

Maximum length of 254 characters.

Example

John Smith

Potential errors

The Contact Name is missing or exceeds the character limit.

D

Business Telephone Number

The telephone number of the person who may be contacted about this site.

Format

  • Minimum length of 10 characters
  • Maximum length of 254 characters

Example

613–174–5555 x993

Potential errors

The Business Telephone Number is missing or exceeds the character limit.

E

E-mail address

The email address of the person who may be contacted about this site.

Format

  • Maximum length 254 characters
  • For multiple email addresses, separate them with commas

Example

john.smith@mail.com,jane.brown@mail.com

Potential errors

The E-mail Address is missing or exceeds the character limit.

F

Station location

The location of the station. This field is also used for NOCHANGES and NOSTATIONS.

Format

If you currently have a station
If you currently have a station deployed, enter the location of your station (maximum length of 63 characters).

If you have no changes to stations
If you have no changes to your station information, enter “NOCHANGES” and leave columns G to BB empty.

If you have no stations deployed
If you have no station deployed or all your stations are being decommissioned, enter “NOSTATIONS” and leave columns G to BB empty.

Example

WR0123 - Strandherd Repeater Site

Potential errors

The Station Location is missing or exceeds the character limit.

An error in this field may also introduce errors in the following fields:

  • L - Latitude
  • M - Longitude
  • AD - Downlink resource allocation

G

Station type

The type of station

Format

Must enter FX.

Example

FX

Potential errors

The Station Type is not input as CAPS, is missing or is not an accepted Station Type value.

H

Radio technology

The mode of operation (provisioning) for the radio apparatus at the site.

Format

Must be one of the following codes:

Code Technology
GSM Global System for Mobile Communications
CDMA Code Division Multiple Access
HSPA High Speed Packet Access
LTE Long Term Evolution
5GNR 5G New Radio
5GDSS 5G Dynamic Spectrum Sharing
WIMAX Worldwide Interoperability for Microwave Access
WI-FI WI-FI
OTHER OTHER

Example

LTE

Potential errors

The Radio Technology value is missing, not in ALL CAPS, or not one of the allowed values.

I

Cell ID

The mobile network Cell Global Identity (CGI) following the 3GPP notation for the given radio technology.

Required when

This field is required when H - Radio technology is any of the following:

  • GSM
  • CDMA
  • HSPA
  • LTE
  • 5GNR
  • 5GDSS

Format

For GSM, CDMA, HSPA
(CGI): PLMN-LAC-CID

For LTE
(ECGI): PLMN-TAC-ECI

For 5GNR, 5GDSS
(NCGI): PLMN-TAC-NCI

Example

302610-1051200-25381093417

Potential errors

The Cell ID is missing or not in the expected format or length.

J

Physical Cell ID

The Physical Cell Identity (PCI) for LTE or 5G systems.

Required when

This field is required when H - Radio technology is any of the following:

  • LTE
  • 5GNR
  • 5GDSS

Format

Must be a number from either:

  • 0 to 503 for LTE systems
  • 0 to 1007 for 5GNR or 5GDSS systems

Example

204

Potential errors

The Physical Cell ID is missing or not within the expected range of values.

K

Province/Territory Code

The two-character abbreviation of the province or territory your station is located in.

Format

Your licence coordinates must be within the province or territory.


Must be one of the following provincial or territorial codes:

Code Province / Territory
AB Alberta
BC British Columbia
MB Manitoba
NB New Brunswick
NL Newfoundland and Labrador
NS Nova Scotia
ON Ontario
PE Prince Edward Island
QC Quebec
SK Saskatchewan
NT Northwest Territories
NU Nunavut
YT Yukon
IP Interprovincial
CA Canada-wide

Example

ON

Potential errors

The Province/Territory is not input as CAPS, is missing or is not an accepted Province/Territory abbreviation.

L

Latitude

The latitudinal coordinate of the station.

Format

  • Must be in decimal degrees using the WGS84 format
  • Must be a location within the licence area
  • Must be between 41 to 90
  • A minimum of four decimal places may be entered if coordinates are not exact
  • A maximum of seven decimal places
  • If P - Site Structure Type Code is "M" (transportable), then report the current operating latitude, not the radius of operation

Example

45.3514035

Potential errors

The Latitude is missing or not within the expected range. The site coordinates may not fall within the licensed service area.

M

Longitude

The longitudinal coordinate of the station.

Format

  • Must be in decimal degrees using the WGS84 format
  • Must be a location within the licence area
  • Must be between -141 to -40
  • A minimum of four decimal places may be entered if coordinates are not exact
  • A maximum of seven decimal places
  • If P - Site Structure Type Code is "M" (transportable), then report the current operating longitude, not the radius of operation

Example

-75.6533946

Potential errors

The Longitude is missing or not within the expected range (use negative to indicate degrees west). The site coordinates may not fall within the licensed service area.

N

Site Type Code

The general type of site associated with the installation.

Format

Must be one of the following codes

Code Site type
U Underground (e.g. a mine or a subway)
O Outdoor (e.g. a tower or rooftop)
I Indoor (e.g. a stadium or office)

Example

O

Potential errors

The Site Type Code is not input as CAPS, is missing or is not an accepted Site Type Code value.

O

Structure height

The total height (m) above ground level of an outdoor structure, such as a tower or rooftop, where antennas are mounted. This structure might also be shared with other radio installations.

Required when

This field is required when N - Site Type Code is O.

Format

  • Must be a number
  • Must be greater than the antenna height
  • Must be between 1 to 600 (m)
  • For equipment mounted on top of a building or its boundaries, add together the total height of the building and the antenna’s supporting structure.

Example

15

Potential errors

The Structure Height is missing or not within the expected range of values.

An error in this field may also give errors in the following fields:

  • AM - Tx Antenna Height
  • AN - Rx Antenna Height

P

Site Structure Type Code

The type of structure in use at the site.

Format

Must be one of the following codes

Code Site structure type
T Purpose-built tower
R Exterior of building (e.g. rooftop)
P Light pole, other street electrical, or utility pole
S Water tower or farm silo
F Furniture
M Transportable
O Other (e.g. indoor)

Example

T

Potential errors

The Structure Type Code is not input as CAPS, is missing or is not an accepted Structure Type Code value.

Q

Date of Last Modification

The date that the installation went into service. This date helps investigate possible sources of technical issues.

Format

  • Must be a date in the past
  • Must be in the format of YYYY-MM-DD

Example

2022-02-14

Potential errors

The date is missing or not in the expected format or range. ORA-01841: (full) year must be between -4713 and +9999, and not be 0.

If you have an improper date format, other errors may not be shown.

R

Site Record ID

An identifier defined by the licensee for the site or antenna installation. We do not validate whether this is unique.

Format

No restriction

Example

1234567890

Potential errors

The Site Record ID is missing.

S

Tx Channel Frequency

The centre frequency (MHz) of the occupied bandwidth as well as any installations that are used unidirectionally for transmission or reception only.

Format

  • Must be within an authorized frequency band for this licence
  • Must be the centre frequency
  • If your antenna is receive only and not transmitting, enter 0

Example

1925.3

Potential errors

The Tx Channel Frequency is missing or not within an authorized frequency band for this licence.

T

Rx Channel Frequency

The centre frequency (MHz) of the occupied bandwidth for the given antenna installation, as well as any installations that are used unidirectionally for transmission or reception only.

Format

  • Must be within an authorized frequency band for this licence
  • Must be the centre frequency
  • If your antenna is transmit only and not receiving enter 0

Example

1875.3

Potential errors

The Rx Channel Frequency is missing or not within an authorized frequency band for this licence.

U

Tx Radio Hardware Version Identification Number (HVIN)

The transmitting radio’s Hardware Version Identification Number (HVIN) certified by ISED. If the radio is certification-exempt, please provide the manufacturer's radio model number or a system configuration name.

Required when

This field is required for any antennas that transmit.

Format

  • Maximum length 128 characters

Example

T99W175MC

Potential errors

The Tx Radio HVIN is missing or exceeds the character limit.

V

Rx Radio Hardware Version Identification Number (HVIN)

The receiving radio’s Hardware Version Identification Number (HVIN) certified by ISED. If the radio is certification-exempt, please provide the manufacturer's radio model number or a system configuration name.

Required when

This field is required for any antennas that receive.

Format

  • Maximum length 128 characters

Example

T99W175MC

Potential errors

The Rx Radio HVIN is missing or exceeds the character limit.

W

Tx Radio Manufacturer Code

The company code assigned by ISED’s Certification and Engineering Bureau (CEB) to the manufacturer of the radio transmitter.

Required when

This field is required for any antennas that transmit

Format

  • Must be a valid manufacturer company number

Example

109AB

Potential errors

The Tx Radio Manufacturer Code is missing or is not an accepted Manufacturer Code value.

X

Rx Radio Manufacturer Code

The company code assigned by ISED’s Certification and Engineering Bureau (CEB) to the manufacturer of the radio receiver.

Required when

This field is required for any antennas that receive

Format

  • Must be a valid manufacturer company number

Example

109AB

Potential errors

The Rx Radio Manufacturer Code is missing or is not an accepted Manufacturer Code value.

Y

Tx Radio Certification Number

The Certification Number assigned by ISED to the radio transmitter and listed in the Radio Equipment List (REL).

Required when

This field is required for any antennas that transmit

Format

  • Must be a valid certification number from the Radio Equipment List (subservice 12-142)
  • If your equipment is exempt from certification, you must enter "Exempt"
  • Maximum length 31 characters

Example

24374-T99W175M

Potential errors

The Tx Radio Certification Number is missing or exceeds the character limit.

Z

Rx Radio Certification Number

The Certification Number assigned by ISED to the radio receiver and listed in the Radio Equipment List (REL).

Required when

This field is required for any antennas that receive

Format

  • Must be a valid certification number from the Radio Equipment List (subservice 12-142)
  • If your equipment is exempt from certification, you must enter "Exempt"
  • Maximum length 31 characters

Example

24374-T99W175M

Potential errors

The Rx Radio Certification Number is missing or exceeds the character limit.

AA

Bandwidth

The channel bandwidth (kHz) of the emission (Transmit) signal. It corresponds to the bandwidth containing 99% of the transmitted power.

Format

  • A number between 0.10 to 50000.00

Example

2300

Potential errors

The Bandwidth is missing or not within the expected range.

AB

Class of Emission

The International Telecommunication Union (ITU) designation for the class of emission.

Format

  • Must be a valid emission code as described in Valid Class of Emission Codes.
  • Enter the emission class that uses the largest bandwidth

Example

F3WET

Potential errors

The Class of Emission is missing or not in the expected format or length.

AC

Transmitter TCP–TRP

The Total Radiated Power (TRP) or Total Conducted Power (TCP) in dBm.

Ensure the value entered is expressed in dBm.

Required when

This field is required for any antennas that transmit.

Format

  • Must be a number
  • Enter TRP for AAS equipment (as defined in the applicable SRSP)
  • Enter TCP for non-AAS equipment

Example

21.4

Potential errors

The Transmitter TCP or TRP is missing, or not within the expected range.

AD

Downlink Resource Allocation

The percentage of time transmitting.

Format

  • For bidirectional systems that transmit and receive on the same frequency (TDD), enter the percentage of time transmitting from 1 to 99 (see GL-01).
  • For full duplex systems, enter 100.

Example

89

Potential errors

The Downlink Resource Allocation is missing or not within the expected range.

AE

Tx Antenna Type Code

The type of antenna associated with a transmitting radio installation.

Required when

This field is required for any antennas that transmit

Format

Must be one of the following codes:

Code Antenna type
AAS Active antenna systems
NAC Non-AAS correlated
NAU Non-AAS uncorrelated

If deploying a hybrid mode, enter NAC.

Example

NAU

Potential errors

The Tx Antenna Type Code is not input as CAPS, is missing or is not an accepted Antenna Type Code value.

AF

Rx Antenna Type Code

The type of antenna associated with a receiving radio installation.

Required when

This field is required for any antennas that receive

Format

Must be one of the following codes:

Code Antenna type
AAS Active antenna systems
NAC Non-AAS correlated
NAU Non-AAS uncorrelated

If deploying a hybrid mode, enter NAC.

Example

NAU

Potential errors

The Rx Antenna Type Code is not input as CAPS, is missing or is not an accepted Antenna Type Code value.

AG

Tx Number of Antennas

The total number of Tx antennas.

Required when

This field is required for any antennas that transmit.

Format

  • For a single-input and single-output (SISO) system enter 1
  • For a traditional antenna diversity, enter the number of installed antennas (2 or higher)
  • For MIMO systems, enter the number of antenna elements in the antenna panel

Example

1

Potential errors

The Number of Tx Antennas is missing or not within the expected range.

AH

Rx Number of Antennas

The total number of Rx antennas.

Required when

This field is required for any antennas that receive.

Format

  • For a single-input and single-output (SISO) system enter 1
  • For a traditional antenna diversity, enter the number of installed antennas (2 or higher)
  • For MIMO systems, enter the number of antenna elements in the antenna panel

Example

1

Potential errors

The Number of Rx Antennas is missing or not within the expected range.

AI

Tx Antenna Model Number

The model number of the transmitter antenna.

Required when

This field is required for any antennas that transmit.

Format

  • If the antenna is integrated into the radio, enter "Integrated"
  • Maximum length of 80 characters.

Example

SV460-SF1 (V)

Potential errors

The Tx Antenna Model Number is missing or exceeds the character limit.

AJ

Rx Antenna Model Number

The model number of the receiver antenna.

Required when

This field is required for any antennas that receive.

Format

  • If the antenna is integrated into the radio, enter "Integrated"
  • Maximum length of 80 characters.

Example

SV460-SF1 (V)

Potential errors

The Rx Antenna Model Number is missing or exceeds the character limit.

AK

Tx Antenna Manufacturer Code

The full name of the manufacturer of the transmitter antenna.

If the antenna is integrated, the value here must match W - Tx Radio Manufacturer Code.

Required when

This field is required for any antennas that transmit

Format

Maximum length of 255 characters.

Example

XYZ antenna manufacturer

Potential errors

The Tx Antenna Manufacturer is missing or exceeds the character limit.

AL

Rx Antenna Manufacturer Code

The full name of the manufacturer of the receiver antenna.

If the antenna is integrated, the value here must match X - Rx Radio Manufacturer Code.

Required when

This field is required for any antennas that receive

Format

Maximum length of 255 characters.

Example

XYZ antenna manufacturer

Potential errors

The Rx Antenna Manufacturer is missing or exceeds the character limit.

AM

Tx Antenna Height

Height (m) of physical centre of the transmitter antenna above or below ground level in meters including the structure/building on which the antenna is mounted.

Required when

This field is required for any antennas that transmit.

Format

Must be a number.

If N - Site Type Code is O (Outdoor):
The antenna height must be between 0 to 600 m and no more than 5 m taller than the O - Structure height.

If N - Site Type Code is I (Indoor):
The antenna height must be between 0 to 600 m.

If N - Site Type Code is U (Underground):
The antenna height must be between -100 to 0 m.

Example

15

Potential errors

The Tx Antenna Height is missing or not within the expected range.

AN

Rx Antenna Height

Height (m) of physical centre of the receiver antenna above or below ground level in meters including the structure/building on which the antenna is mounted.

Required when

This field is required for any antennas that receive.

Format

Must be a number.

If N - Site Type Code is O (Outdoor):
The antenna height must be between 0 to 600 m and no more than 5 m taller than the O - Structure height.

If N - Site Type Code is I (Indoor):
The antenna height must be between 0 to 600 m.

If N - Site Type Code is U (Underground):
The antenna height must be between -100 to 0 m.

Example

15

Potential errors

The Rx Antenna Height is missing or not within the expected range.

AO

Tx Omnidirectional Antenna Pattern Indicator

Whether the transmitter antenna is omnidirectional or directional.

Required when

This field is required for any antennas that transmit.

Format

Must be one of the following codes:

Code Antenna pattern
D Directional
N Non-directional

Leave blank if the antenna does not transmit.

Example

D

Potential errors

The Tx Omnidirectional Pattern Indicator is not input as CAPS, is missing or is not an accepted Directional Pattern Code value.

An error in this field may also give errors for the following fields:
  • AQ - Tx Antenna Horizontal Beam
  • AS - Tx Antenna Vertical Beam
  • AU - Tx Antenna Azimuth
  • AW - Tx Antenna Elevation Angle

AP

Rx Omnidirectional Antenna Pattern Indicator

Whether the receiver antenna is omnidirectional or directional.

Required when

This field is required for any antennas that receive.

Format

Must be one of the following codes

Code Antenna pattern
D Directional
N Non-directional

Leave blank if the antenna does not receive.

Example

D

Potential errors

The Rx Omnidirectional Pattern Indicator is not input as CAPS, is missing or is not an accepted Directional Pattern Code value.

An error in this field may also give errors for the following fields:
  • AR - Rx Antenna Horizontal Beam
  • AT - Rx Antenna Vertical Beam
  • AV - Rx Antenna Azimuth
  • AX - Rx Antenna Elevation Angle

AQ

Tx Antenna Horizontal Beam

The beam steering angle for AAS (Active Antenna Systems) or the beam width in the horizontal plane for non-AAS.

Required when

This field is required when AO - Tx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

For AAS
Enter the horizontal beam steering angle range around the mean value specified by AU - Tx Antenna Azimuth.

For non-AAS
Enter the half-power (3 dB) beam width in the horizontal plane of the main lobe for the transmitter antenna.

Must be a number from 1.0 to 359.9 (degrees).

Example

120

Potential errors

The Tx Antenna Horizontal Beamwidth is missing or not within the expected range.

AR

Rx Antenna Horizontal Beam

The beam steering angle for AAS (Active Antenna Systems) or the beam width in the horizontal plane for non-AAS.

Required when

This field is required when AP - Rx Omnidirectional Antenna Pattern Indicator is D (Directional).

For AAS
Enter the horizontal beam steering angle range around the mean value specified by AV - Rx Antenna Azimuth.

For non-AAS
Enter the half-power (3 dB) beam width in the horizontal plane of the main lobe for the receiver antenna.

Must be a number from 1.0 to 359.9 (degrees).

Example

120

Potential errors

The Rx Antenna Horizontal Beamwidth is missing or not within the expected range.

AS

Tx Antenna Vertical Beam

Required when

This field is required when AO - Tx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

For AAS
Enter the vertical beam steering angle range around the mean value specified by AW - Tx Antenna Elevation Angle.

For non-AAS
Enter the half-power (3 dB) beam width in the vertical plane of the main lobe for the transmitter antenna.

Must be a number from 1.0 to 359.9 (degrees).

Example

135

Potential errors

The Tx Antenna Vertical Beamwidth is missing or not within the expected range.

AT

Rx Antenna Vertical Beam

The beam elevation angle for AAS (Active Antenna Systems) or the beam width in the vertical plane for non-AAS.

Required when

This field is required when AP - Rx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

For AAS
Enter the vertical beam steering angle range around the mean value specified by AX - Rx Antenna Elevation Angle.

For non-AAS
Enter the half-power (3 dB) beam width in the vertical plane of the main lobe for the receiver antenna.

Must be a number from 1.0 to 359.9 (degrees).

Example

135

Potential errors

AU

Tx Antenna Azimuth

The azimuth (in degrees) of the antenna from true north of the transmitter antenna's direction of maximum radiation.

Required when

This field is required when AO - Tx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

Must be a number from 0.0 to 359.9 (degrees).

Example

270

Potential errors

The Tx Antenna Azimuth is missing or not within the expected range.

AV

Rx Antenna Azimuth

The azimuth (in degrees) of the antenna from true north of the receiver antenna's direction of maximum radiation.

Required when

This field is required when AP - Rx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

Must be a number from 0.0 to 359.9 (degrees).

Example

270

Potential errors

The Rx Antenna Azimuth is missing or not within the expected range.

AW

Tx Antenna Elevation Angle

The transmitter antenna’s vertical elevation angle of the main lobe with reference to the horizontal ground in degrees. Includes any mechanical and electrical beam tilt.

Required when

This field is required when AO - Tx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

  • Must be a number from -90.0 to 90.0 (degrees).
  • Use positive values for antennas tilted upward.
  • Use negative values for antennas tilted downward.

Example

0.5

Potential errors

The Tx Antenna Elevation Angle is missing or not within the expected range.

AX

Rx Antenna Elevation Angle

The receiver antenna’s vertical elevation angle of the main lobe with reference to the horizontal ground in degrees. Includes any mechanical and electrical beam tilt.

Required when

This field is required when AP - Rx Omnidirectional Antenna Pattern Indicator is D (Directional).

Format

  • Must be a number from -90.0 to 90.0 (degrees).
  • Use positive values for antennas tilted upward.
  • Use negative values for antennas tilted downward.

Example

0.5

Potential errors

The Rx Antenna Elevation Angle is missing or not within the expected range.

AY

Tx Antenna Gain

The gain of the transmitter antenna expressed relative to an isotropic radiator (dBi). For AAS, the gain would represent the gain of the individual antenna element.

Required when

This field is required for any antennas that transmit.

Format

Must be a number from 0.0 to 70.0 (dBi).

For a directional antenna, enter the gain in the direction of maximum radiation.

Example

41.3

Potential errors

The Tx Antenna Gain is missing or not within the expected range.

AZ

Rx Antenna Gain

The gain of the receiver antenna expressed relative to an isotropic radiator (dBi). For AAS, the gain would represent the gain of the individual antenna element.

Required when

Format

Must be a number from 0.0 to 70.0 (dBi).

For a directional antenna, enter the gain in the direction of maximum radiation.

Example

41.3

Potential errors

The Rx Antenna Gain is missing or not within the expected range.

Required when

Format

Example

2.5

Potential errors

Required when

Format

Example

2.5

Potential errors

The Rx Line Loss is missing or not within the expected range.
